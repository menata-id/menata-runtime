Process Overlay — display requirements

Derived from brd-menata-runtime-v2.md §7–9: five screens that make a declared process block legible without reading raw metadata. Each is a standalone static page — click through with the nav above (htmx hx-boost is wired on it), interactive bits use hyperscript only, exactly like the real app's own CAP-V14/V15/V16/V21 widgets.

CAP-W05
Process Map

Read-only state/transition graph rendered from a Machine's process block, richer than today's two-table view.
CAP-W01
Requirement Checklist

What a transition needs before it fires — form fields, evidence with cardinality, tasks — read from maintained counters, never queried live.
CAP-W03
Quorum Approval

ALL / ANY / N_OF_M approval widget — who has decided, who's pending, and whether quorum is already met.
CAP-W04
SLA Badge

On-track / warning / breached states for a state's SLA, as a list-row pill and as a detail-page banner.
