CASE 19 · PROJECT MANAGEMENT

Trello-like Project Workspace

A composable project-management surface where Boards contain Lists and Lists contain Cards. Cards can be reordered and moved across lists, while the same domain data can be rendered as board, timeline, calendar and dashboard views.

Open Board →Card Detail

Project UI showcase

Ten screens are represented by the two existing core mockups plus these composable view explorations.

01 · Board Workspace

Lists, cards, labels, members and drag/drop.

02 · Task Detail

Description, checklist, activity, comments and metadata.

03 · Timeline / Roadmap

Workstreams, bars, milestones and dates.

04 · Calendar

Due dates, scheduled work and milestones.

05 · Sprint Dashboard

Completion, burndown, workload and blockers.

06 · Team Capacity

Members, allocation and active ownership.

07 · Workflow Automation

Trigger → condition → action metadata.

08 · Board Settings

Statuses, labels, custom fields and permissions.

09 · Collaboration

Comments, activity, attachments and member assignment.

10 · Project Insights

A composed reporting surface over the same records.

Composable metadata model

Board → contains ordered Lists

List → contains ordered Cards

Card → composes labels, members, checklist, dates, attachments and comments

View metadata → chooses Board, Timeline, Calendar or Dashboard rendering

Capability focus

This case is the portfolio's manual-ordering benchmark: list order, card order and cross-column movement are first-class interactions rather than a cosmetic Kanban rendering.
